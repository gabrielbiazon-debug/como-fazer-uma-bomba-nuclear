# ⚡ VoltAuto - Website de Veículos Elétricos

Este é o repositório do site institucional e promocional da **VoltAuto**, focado em apresentar os diferenciais e a tecnologia de veículos 100% elétricos.

## 🚀 Sobre o Projeto

O projeto foi desenvolvido para oferecer uma experiência moderna, leve e responsiva aos usuários interessados em mobilidade sustentável. O site apresenta destaques como autonomia, tempo de recarga e uma chamada direta para agendamento de *test drive*.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização responsiva com *Flexbox* e *CSS Grid* (sem dependência de frameworks externos).
* **Unsplash API/Images:** Imagens de alta qualidade para o fundo do cabeçalho.
